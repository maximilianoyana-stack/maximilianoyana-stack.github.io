# Estructura del Repositorio

Raíz del proyecto y descripción rápida de carpetas/archivos relevantes:

- `index.html` — Página principal (hero 90vh, CTA a `itinerario.html`).
- `destinos.html` — Listado de destinos y mapa (iframe embed).
- `culturas.html` — Página de culturas y tradiciones.
- `gastronomia.html` — Gastronomía local.
- `itinerario.html` — Formulario de reservas y detalles de itinerarios.
- `blog.html` — Entradas y comentarios locales.
- `css/style.css` — Estilos globales y reglas para heros/carousels/cards.
- `js/main.js` — Lógica principal: carga de datos, renderizado de carruseles, modales.
- `js/idiomas.js` — Diccionario y funciones de i18n.
- `data/` — JSON con contenido; por ejemplo `destinos.json`.
- `img/` — Imágenes organizadas por carpeta (`Destinos`, `cards`, `Pictures`, `Puno`).

Archivos para entregar / revisar:
- `README.md` — (este archivo) guía rápida del proyecto.
- `Informe_Tecnico.md` — plantilla de informe técnico.

Recomendación: mantener rutas relativas y verificar que `data/*.json` y `img/` usen nombres sin espacios o estandarizados para evitar problemas en servidores.
